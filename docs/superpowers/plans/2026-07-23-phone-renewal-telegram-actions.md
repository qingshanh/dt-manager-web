# 手机号续费与 Telegram 操作实施计划

## 目标

- 将续费从通用 CommonRest 改为 App 使用的原生 `orderPrivateNumber` RPC。
- TalkU/说道与 Dingtone/叮咚沿用各自 `appVariant` 会话身份和币种文案。
- 到期提醒显示完整号码、当前余额、续期费用和每次续期期限。
- Telegram 续期与取消按钮必须经过二次确认，并拒绝重复或过期确认。
- 续期结果通知显示续期前后余额、实际延长期限和新到期时间。
- 继续保留本地已取消号码；仅在现有远端接口能返回历史记录时回填缺失数据。

## 实施顺序

1. 增加原生续费、通知字段和 Telegram 回调协议的失败测试。
2. 让 `renewPhoneNumber` 使用已注册会话调用 `callOrderPrivateNumberJson`，写入后不自动重试。
3. 增加续费费用、期限、币种及余额格式化，并接入到期和成功通知。
4. 增加续期/取消请求与最终确认回调，使用号码状态指纹和进程内锁防止重放。
5. 静态核对 App 当前号码列表接口是否包含历史取消记录；没有则不补录。
6. 运行针对性测试、TypeScript 构建和前端构建，不自动触发真实扣费操作。
